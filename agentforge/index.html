问题任务流程设计取舍当前实现

代码改完以后，
过程还能说清吗？

Coding Agent 能修改代码，但复杂任务还需要明确范围、保留审批、记录验证与复盘结果。AgentForge 基于开源 Pi 扩展系统，为开发任务增加一层可追踪的工作流。

把执行放进流程

  1. 01

    探索与调研

    收集项目上下文、约束与参考来源。

  2. 02

    计划与审批

    保存结构化计划，在进入执行前保留人工审批。

  3. 03

    执行与治理

    通过策略规则检查工具调用与操作范围。

  4. 04

    验证与复盘

    记录测试、构建结果，生成报告与工作流评估。

让结果有据可查

扩展已有运行时

Pi 承担底层 Agent 运行与工具交互，项目聚焦工作流层的控制与记录。

保存结构化状态

计划、审批、策略事件和验证记录随任务保存，支持事后复查。

用报告承接过程

提供 Markdown、JSON 与 HTML 报告生成模块，并内置任务看板演示项目。

当前实现

仓库包含 CLI、Pi 扩展、策略、验证、报告模块及测试代码。多角色部分主要提供角色分配与任务说明；MCP 部分主要提供工具清单与映射，不等于已验证的完整多 Agent 调度或通用 MCP 执行平台。内置演示报告使用构造样例。本轮未重新运行测试或验证完整端到端任务。
